This guide walks through creating a Swap blockchain action: selecting tokens, generating builder metadata, registering the blockchain action, and verifying it appears in the directory.

## Prerequisites

- A Relayer API key (see [Authentication](/get-started/authentication))
- Your account activated with the Action module enabled

<CodeGroup>

```bash Environment
export RELAYER_API_KEY="sk_client_key_v1_your_key_here"
export RELAYER_BASE_URL="https://relayer-api.onrender.com"  # or https://api.relayer.fi for production
```

</CodeGroup>

## Steps

<Steps>
  <Step title="Get the token list for your chain and protocol">
    Fetch the supported tokens for your target chain and DeFi protocol before building the metadata. This ensures the tokens you configure are valid for the action.

    <CodeGroup>

    ```bash cURL
    curl -X GET "$RELAYER_BASE_URL/v1/action/tokens/polygon/uniswap" \
      -H "Authorization: ApiKey $RELAYER_API_KEY"
    ```

    ```typescript Node.js
    const response = await fetch(
      `${RELAYER_BASE_URL}/v1/action/tokens/polygon/uniswap`,
      {
        headers: { "Authorization": `ApiKey ${apiKey}` },
      }
    );
    const { data } = await response.json();
    // data — array of supported tokens: { symbol, address, decimals, logoURI }
    console.log(`Available tokens: ${data.map((t: any) => t.symbol).join(", ")}`);
    ```

    </CodeGroup>

    Use the token addresses from this response in the next step.
  </Step>

  <Step title="Generate swap metadata with the builder">
    Call the Swap builder to generate structured action metadata. This defines what the blockchain action does when a user interacts with it.

    <CodeGroup>

    ```bash cURL
    curl -X POST $RELAYER_BASE_URL/v1/action/builders/swap \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "chain": "polygon",
        "protocol": "uniswap",
        "fromToken": "0xMATICAddress",
        "toToken": "0xUSDCAddress",
        "amount": "10"
      }'
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/action/builders/swap`, {
      method: "POST",
      headers: {
        "Authorization": `ApiKey ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        chain: "polygon",
        protocol: "uniswap",
        fromToken: "0xMATICAddress",
        toToken: "0xUSDCAddress",
        amount: "10",
      }),
    });
    const { data } = await response.json();
    // data — the complete action metadata object
    const metadata = data;
    ```

    </CodeGroup>

    The builder returns a metadata object that fully describes the swap action — token addresses, protocol routing, chain configuration, and UI display hints.
  </Step>

  <Step title="Create the blockchain action in the registry">
    Register the blockchain action using the metadata from the builder. This creates your operator's record and publishes the app to the directory.

    <CodeGroup>

    ```bash cURL
    curl -X POST $RELAYER_BASE_URL/v1/action \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "name": "MATIC to USDC Swap",
        "description": "Swap MATIC for USDC on Polygon via Uniswap",
        "type": "swap",
        "metadata": { "...builderOutputHere": true }
      }'
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/action`, {
      method: "POST",
      headers: {
        "Authorization": `ApiKey ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        name: "MATIC to USDC Swap",
        description: "Swap MATIC for USDC on Polygon via Uniswap",
        type: "swap",
        metadata,
      }),
    });
    const { data } = await response.json();
    // data.id — your blockchain action ID
    // data.status — "active"
    const miniAppId = data.id;
    console.log(`Blockchain action created: ${miniAppId}`);
    ```

    </CodeGroup>

    <Tip>
      Save the `miniAppId` — you need it for metadata retrieval, updates, and event indexing.
    </Tip>
  </Step>

  <Step title="Verify the blockchain action appears in the directory">
    Confirm your blockchain action is discoverable by querying the public directory.

    <CodeGroup>

    ```bash cURL
    curl -X GET $RELAYER_BASE_URL/v1/action/directory
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/action/directory`);
    const { data } = await response.json();
    const myApp = data.find((app: any) => app.id === miniAppId);
    console.log(`Blockchain action in directory: ${!!myApp}`);
    ```

    </CodeGroup>

    The directory is public — no API key needed for reads. Embedders query this endpoint to discover available actions for their platform.
  </Step>

  <Step title="Index an on-chain execution event">
    When a user executes your blockchain action on-chain, report the event to Relayer. This powers rewards tracking and KOL analytics.

    <CodeGroup>

    ```bash cURL
    curl -X POST $RELAYER_BASE_URL/v1/action/indexing/events \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "miniAppId": "app_abc123",
        "txHash": "0xTransactionHashHere",
        "userAddress": "0xUserWalletAddress",
        "referrerAddress": "0xKOLWalletAddress",
        "chainId": 137
      }'
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/action/indexing/events`, {
      method: "POST",
      headers: {
        "Authorization": `ApiKey ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        miniAppId: "app_abc123",
        txHash: "0xTransactionHashHere",
        userAddress: "0xUserWalletAddress",
        referrerAddress: "0xKOLWalletAddress",
        chainId: 137,
      }),
    });
    const { data } = await response.json();
    // data.indexed === true
    ```

    </CodeGroup>

    The `referrerAddress` links the execution to a KOL for rewards attribution. Omit if the execution was not referred.
  </Step>

  <Step title="Query KOL rewards metrics">
    Check on-chain performance metrics for a KOL address — volume, executions, and referred blockchain actions.

    <CodeGroup>

    ```bash cURL
    curl -X GET "$RELAYER_BASE_URL/v1/action/rewards/metrics?address=0xKOLWalletAddress" \
      -H "Authorization: ApiKey $RELAYER_API_KEY"
    ```

    ```typescript Node.js
    const params = new URLSearchParams({
      address: "0xKOLWalletAddress",
    });
    const response = await fetch(
      `${RELAYER_BASE_URL}/v1/action/rewards/metrics?${params}`,
      {
        headers: { "Authorization": `ApiKey ${apiKey}` },
      }
    );
    const { data } = await response.json();
    // data.totalExecutions — how many times their referrals executed
    // data.totalVolume — aggregated on-chain volume attributed to this KOL
    console.log(`KOL executions: ${data.totalExecutions}, volume: ${data.totalVolume}`);
    ```

    </CodeGroup>
  </Step>
</Steps>

## Updating a Blockchain Action

Update metadata or display info for an existing blockchain action:

```typescript Node.js
const response = await fetch(`${RELAYER_BASE_URL}/v1/action/${miniAppId}`, {
  method: "PATCH",
  headers: {
    "Authorization": `ApiKey ${apiKey}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    description: "Updated description",
    metadata: updatedMetadata,
  }),
});
```

## Retrieving Raw Metadata

Get the raw metadata object for any blockchain action by ID:

```bash cURL
curl "$RELAYER_BASE_URL/v1/action/$MINI_APP_ID/metadata" \
  -H "Authorization: ApiKey $RELAYER_API_KEY"
```
