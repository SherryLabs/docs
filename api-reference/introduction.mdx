## Overview

The Relayer API provides programmatic access to the full platform. Endpoints are organized by Kit -- Exchange, Signing, Payout, and Action -- so you can find the operations you need based on the domain you are integrating.

## Base URL

```
https://api.relayer.fi
```

## Authentication

All API endpoints require authentication via the `Authorization` header with an `ApiKey` prefix. Include your API key in every request:

```bash
curl -H "Authorization: ApiKey sk_your_api_key" \
  https://api.relayer.fi/v1/health
```

For details on obtaining and managing API keys, see the [Authentication guide](/get-started/authentication).

Use the sidebar to browse endpoints by Kit. Each tag groups related operations so you can quickly find what you need for your integration.
