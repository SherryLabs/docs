This guide walks through a complete OTC crypto buy trade: activating your operator account, configuring spread, quoting a rate, creating a trade, confirming cash receipt, and releasing escrow.

## Prerequisites

- A Relayer API key (see [Authentication](/get-started/authentication))
- Your account activated with the Exchange module enabled

<CodeGroup>

```bash Environment
export RELAYER_API_KEY="sk_client_key_v1_your_key_here"
export RELAYER_BASE_URL="https://relayer-api.onrender.com"  # or https://api.relayer.fi for production
```

</CodeGroup>

## Steps

<Steps>
  <Step title="Activate as an OTC operator">
    Before trading, register your operator account with the Exchange Kit.

    <CodeGroup>

    ```bash cURL
    curl -X POST $RELAYER_BASE_URL/v1/exchange/activate \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json"
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/exchange/activate`, {
      method: "POST",
      headers: {
        "Authorization": `ApiKey ${apiKey}`,
        "Content-Type": "application/json",
      },
    });
    const { data } = await response.json();
    // data.status === "active"
    ```

    </CodeGroup>

    You only need to do this once. Check status at any time with `GET /v1/exchange/operator/status`.
  </Step>

  <Step title="Configure your spread">
    Set the buy and sell spread percentages you want to apply to all quotes. Spread is expressed as a decimal (e.g., `0.02` = 2%).

    <CodeGroup>

    ```bash cURL
    curl -X PATCH $RELAYER_BASE_URL/v1/exchange/operator/spread \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "buySpread": 0.02,
        "sellSpread": 0.025
      }'
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/exchange/operator/spread`, {
      method: "PATCH",
      headers: {
        "Authorization": `ApiKey ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        buySpread: 0.02,
        sellSpread: 0.025,
      }),
    });
    const { data } = await response.json();
    // data.buySpread === 0.02
    ```

    </CodeGroup>

    <Tip>
      Start with a conservative spread while testing. You can update spread at any time — changes apply to the next quote.
    </Tip>
  </Step>

  <Step title="Get a quote">
    Request a price for the trade before committing. Specify the currency pair and the amount your client wants to exchange.

    <CodeGroup>

    ```bash cURL
    curl -X GET "$RELAYER_BASE_URL/v1/exchange/quote?fromCurrency=USD&toCurrency=ETH&amount=1000" \
      -H "Authorization: ApiKey $RELAYER_API_KEY"
    ```

    ```typescript Node.js
    const params = new URLSearchParams({
      fromCurrency: "USD",
      toCurrency: "ETH",
      amount: "1000",
    });

    const response = await fetch(
      `${RELAYER_BASE_URL}/v1/exchange/quote?${params}`,
      {
        headers: { "Authorization": `ApiKey ${apiKey}` },
      }
    );
    const { data } = await response.json();
    // data.rate — the offered exchange rate including your spread
    // data.toAmount — how much ETH the client will receive
    // data.expiresAt — quote expiry timestamp
    console.log(`Rate: ${data.rate}, Receiving: ${data.toAmount} ETH`);
    ```

    </CodeGroup>

    Present the rate to your client. The quote is time-limited — proceed to the next step before it expires.
  </Step>

  <Step title="Create a trade">
    Once your client accepts the quote, create a trade to lock it in.

    <CodeGroup>

    ```bash cURL
    curl -X POST $RELAYER_BASE_URL/v1/exchange/trades \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "fromCurrency": "USD",
        "toCurrency": "ETH",
        "fromAmount": 1000,
        "clientId": "client_abc123",
        "destinationAddress": "0xYourClientWalletAddress"
      }'
    ```

    ```typescript Node.js
    const response = await fetch(`${RELAYER_BASE_URL}/v1/exchange/trades`, {
      method: "POST",
      headers: {
        "Authorization": `ApiKey ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        fromCurrency: "USD",
        toCurrency: "ETH",
        fromAmount: 1000,
        clientId: "client_abc123",
        destinationAddress: "0xYourClientWalletAddress",
      }),
    });
    const { data } = await response.json();
    // data.id — store this trade ID for subsequent steps
    // data.status === "created"
    const tradeId = data.id;
    ```

    </CodeGroup>

    Save the `tradeId` — you need it for the remaining steps.
  </Step>

  <Step title="Confirm cash receipt (pickup)">
    Once your client delivers the cash to you, mark it as picked up. This moves the trade to the next stage.

    <CodeGroup>

    ```bash cURL
    curl -X PATCH $RELAYER_BASE_URL/v1/exchange/trades/$TRADE_ID/pickup \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json"
    ```

    ```typescript Node.js
    const response = await fetch(
      `${RELAYER_BASE_URL}/v1/exchange/trades/${tradeId}/pickup`,
      {
        method: "PATCH",
        headers: {
          "Authorization": `ApiKey ${apiKey}`,
          "Content-Type": "application/json",
        },
      }
    );
    const { data } = await response.json();
    // data.status === "picked_up"
    ```

    </CodeGroup>
  </Step>

  <Step title="Release escrow to complete the trade">
    After confirming cash receipt, release the crypto from escrow to the client's destination address.

    <CodeGroup>

    ```bash cURL
    curl -X POST $RELAYER_BASE_URL/v1/exchange/trades/$TRADE_ID/release \
      -H "Authorization: ApiKey $RELAYER_API_KEY" \
      -H "Content-Type: application/json"
    ```

    ```typescript Node.js
    const response = await fetch(
      `${RELAYER_BASE_URL}/v1/exchange/trades/${tradeId}/release`,
      {
        method: "POST",
        headers: {
          "Authorization": `ApiKey ${apiKey}`,
          "Content-Type": "application/json",
        },
      }
    );
    const { data } = await response.json();
    // data.status === "settled"
    // data.txHash — on-chain transaction hash for the transfer
    console.log(`Trade settled. Transaction: ${data.txHash}`);
    ```

    </CodeGroup>

    The trade is now complete. The client's wallet receives the crypto and your treasury updates automatically.
  </Step>
</Steps>

## Tracking Trade Status

Poll or store the trade status throughout the lifecycle:

```typescript Node.js
const response = await fetch(
  `${RELAYER_BASE_URL}/v1/exchange/trades/${tradeId}`,
  {
    headers: { "Authorization": `ApiKey ${apiKey}` },
  }
);
const { data } = await response.json();
console.log(data.status);
// "created" | "deposit_pending" | "picked_up" | "released" | "settled"
```

List all trades filtered by status:

```bash cURL
curl "$RELAYER_BASE_URL/v1/exchange/trades?status=picked_up" \
  -H "Authorization: ApiKey $RELAYER_API_KEY"
```
