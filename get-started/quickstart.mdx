This guide walks you through making your first Relayer API call. You will verify connectivity with the health endpoint, then make an authenticated request.

## Prerequisites

- An API key from your operator dashboard (see [Authentication](/get-started/authentication))
- `curl` or Node.js installed

## Environments

Relayer provides two environments. Choose the one that matches your stage:

| Environment | Base URL | Use for |
|-------------|----------|---------|
| **Sandbox** | `https://sandbox.relayer.fi` | Testing and development |
| **Production** | `https://api.relayer.fi` | Live operations |

<Warning>
  Sandbox runs on Render free tier — the first request after idle may take 30-60 seconds to cold-start.
</Warning>

## Step 1: Verify Connectivity

Start with the health check endpoint. It requires no authentication and confirms the API is reachable.

<Tabs>
  <Tab title="Sandbox">
    <CodeGroup>

    ```bash cURL
    curl https://sandbox.relayer.fi/health
    ```

    ```typescript Node.js
    const response = await fetch("https://sandbox.relayer.fi/health");
    const data = await response.json();
    console.log(data);
    // Expected: { "status": "ok" }
    ```

    </CodeGroup>
  </Tab>
  <Tab title="Production">
    <CodeGroup>

    ```bash cURL
    curl https://api.relayer.fi/health
    ```

    ```typescript Node.js
    const response = await fetch("https://api.relayer.fi/health");
    const data = await response.json();
    console.log(data);
    // Expected: { "status": "ok" }
    ```

    </CodeGroup>
  </Tab>
</Tabs>

You should receive:

```json
{
  "status": "ok"
}
```

## Step 3: Make an Authenticated Request

Now make a request that requires authentication. This example lists available exchange quotes:

<CodeGroup>

```bash cURL
curl -X GET $RELAYER_BASE_URL/v1/exchange/quotes \
  -H "Authorization: ApiKey $RELAYER_API_KEY" \
  -H "Content-Type: application/json"
```

```typescript Node.js
const baseUrl = process.env.RELAYER_BASE_URL;
const apiKey = process.env.RELAYER_API_KEY;

const response = await fetch(
  `${baseUrl}/v1/exchange/quotes`,
  {
    headers: {
      "Authorization": `ApiKey ${apiKey}`,
      "Content-Type": "application/json",
    },
  }
);

const result = await response.json();
console.log(JSON.stringify(result, null, 2));
```

</CodeGroup>

A successful response looks like:

```json
{
  "success": true,
  "message": "Success",
  "data": [],
  "statusCode": 200,
  "timestamp": "2026-03-28T12:00:00.000Z",
  "path": "/v1/exchange/quotes"
}
```

<Tip>
  An empty `data` array is expected on a fresh account. It means the API authenticated your request successfully — you just have not created any quotes yet.
</Tip>

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `Connection refused` | Check `RELAYER_BASE_URL` — sandbox: `https://sandbox.relayer.fi`, production: `https://api.relayer.fi` |
| `401 Unauthorized` | Verify your `Authorization` header uses `ApiKey` prefix (not `Bearer`) |
| `404 Not Found` | Check the endpoint path starts with `/v1/` |
| Slow first response | Sandbox cold-starts after idle (30-60s). Production does not have this delay. |
