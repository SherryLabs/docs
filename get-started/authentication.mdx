Every request to the Relayer API requires an API key. This guide covers how to get your key, configure environments, and authenticate requests.

## API Keys

You receive your API key when your operator account is created in the Relayer dashboard. Keys follow this format:

```
sk_client_key_v1_340f5c18...
```

<Warning>
  Keep your API key secret. Never expose it in frontend code, public repositories, or client-side JavaScript. Store it in environment variables.
</Warning>

## Environments

Relayer provides two environments:

| Environment | Base URL | Purpose |
|-------------|----------|---------|
| **Sandbox** | `https://relayer-api.onrender.com` | Testing and development |
| **Production** | `https://api.relayer.fi` | Live operations |

Both environments use the same API key format and endpoints. Use the sandbox for development and switch to production when you are ready to go live.

## Making Authenticated Requests

Pass your API key in the `Authorization` header using the `ApiKey` scheme:

```
Authorization: ApiKey sk_client_key_v1_your_key_here
```

<CodeGroup>

```bash cURL
curl -X GET https://relayer-api.onrender.com/v1/exchange/quotes \
  -H "Authorization: ApiKey sk_client_key_v1_your_key_here" \
  -H "Content-Type: application/json"
```

```typescript JavaScript / TypeScript
const response = await fetch(
  "https://relayer-api.onrender.com/v1/exchange/quotes",
  {
    method: "GET",
    headers: {
      "Authorization": "ApiKey sk_client_key_v1_your_key_here",
      "Content-Type": "application/json",
    },
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

  </Tab>
  <Tab title="Error">
```json
{
  "success": false,
  "message": "API key not found",
  "statusCode": 401,
  "timestamp": "2026-03-28T12:00:00.000Z",
  "path": "/v1/exchange/quotes"
}
```
  </Tab>
</Tabs>

## Authentication Errors

| Status Code | Meaning | Common Cause |
|-------------|---------|--------------|
| `401` | Unauthorized | Missing or expired API key |
| `403` | Forbidden | Key lacks permission for this resource |
| `404` | Not Found | API key does not exist |

<Tip>
  If you receive a `401` error, verify that your `Authorization` header uses the exact format `ApiKey sk_client_key_v1_...` -- the `ApiKey` prefix is required.
</Tip>

## Security Best Practices

<Steps>
  <Step title="Use environment variables">
    Store your API key in `.env` files or your platform's secret management (Vercel, Railway, etc.). Never hardcode keys in source code.
  </Step>
  <Step title="Server-side only">
    Only make API calls from your backend. Never include API keys in client-side JavaScript, mobile apps, or browser requests.
  </Step>
  <Step title="Rotate regularly">
    If you suspect a key has been compromised, generate a new one from the dashboard immediately.
  </Step>
</Steps>
